推荐流程

1. 点击“测试 Frame 验证”，完成真实 Figma 环境自检。
2. 选择你的标准 Frame，再点“扫描当前 Frame”。
3. 编辑主题颜色和 Token 映射，查看右侧替换预览。
4. “应用当前主题”修改所选 Frame；勾选主题后“生成主题 Frame”创建副本。
5. 更换 Frame 或手动编辑图层后，请重新扫描。

安全边界

不修改大小、位置、圆角、透明度、字体或 Auto Layout。组件、实例、锁定层、共享样式和变量绑定颜色保持原样并报告。渐变、图片等非纯色填充不修改。批量源 Frame 须在页面顶层，原始源保持不变。

连续切换使用本次扫描的原始颜色，不按上次主题猜测。插件撤销仅覆盖本次扫描后的操作（最多 20 次），外部编辑后会拒绝覆盖。Figma 原生撤销也可使用。主题库存储在当前用户的插件本地存储中；跨设备请导出 JSON 备份。

不需要付费 Variables Modes；无网络请求、无账号、无云同步。RGB 使用 #RRGGBB，画布上的填充透明度和阴影 alpha 保持不变。完全透明或隐藏的纯色也会扫描。
